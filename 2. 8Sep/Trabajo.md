## 2. Formato del esqueleto de HTML

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Título de la Página</title>
  </head>
  <body>
    <!-- El contenido de tu página va aquí -->
  </body>
</html>
```

## 3. Estructura minima accesible

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Inicio - Nombre de tu Sitio</title>
  </head>
  <body>
    <header>
      <!-- Navegación principal -->
    </header>

    <main>
      <h1>Título principal accesible y único</h1>
      <!-- Contenido central de la página -->
    </main>

    <footer>
      <!-- Información de copyright y enlaces secundarios -->
    </footer>
  </body>
</html>
```
