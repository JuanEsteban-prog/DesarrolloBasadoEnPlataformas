## Arquitectura n-capas
- Presentación: Interfaz.
- Lógica del negocio: BackEnd.
- Datos: Asegura la persistencia. 

Tipos de arquitecturas: Monolítico(Depende de sí mismo), cliente-servidor(Para que la interfaz muestre datos se tiene que conectar con el cliente servidor. Pasamos de monolítio a cliente-servidor), Rest y n-capas

Estudiar **patrones de diseño**

- En el desarrollo de un backend que implementa el patrón arquitectónico MVC (Modelo-Vista-Controlador), los patrones de diseño (de tipo creacional, estructural o de comportamiento) se utilizan para resolver problemas específicos dentro de cada capa.
